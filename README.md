## 🔧 Troubleshooting

### Game Crashes on Startup
- Run the game **as Administrator** (right-click exe > "Run as administrator").  
- Update your graphics card drivers (NVIDIA or AMD)to the latest version.  
- Disable your antivirus temporarly, as it may block the game from accessing files.  

### Black Screen or Flickering
- Press **Alt + Enter** to switch between fullscreen and windowed mode.  
- Lowerthe graphics settingsin the config file (open `settings.xml` in the game folder, change `refreshRate` to `60`, set `fullscreen` to `false`).  

### Low FPS / Lag
- Close background apps (Chrome, Discord, Spotify).  
- Set game graphics to **"Low"** or **"Medium"**.  
- Make sure the game is installed on an **SSD** not an HDD, if possible.  

### Missing DLL or Error Messages
- Install **Visual C++ Redistributables** (all versions, 2015-2022)and **DirectX** from the `_Redist` folder inside the game directory.  
- Run `setup.bat` or `install.bat` as Admin if present – it will install required components.  

### Save Game Not Working
- Ensure you have write permissions to the game folder (right-click folder > Properties > Security > Edit > Allow Full Control to Users).  
- Save files are stored in `Documents\Rockstar Games\GTA VI` – make sure that folder exists.
